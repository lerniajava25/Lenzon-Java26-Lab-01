# Elpris-analysator

Laboration 1 — Systemutveckling Java, Lernia (klass Java 26).

Ett konsolprogram i Java som hämtar spotpriser på el från
[elprisetjustnu.se](https://www.elprisetjustnu.se) och analyserar dygnets priser
för valt elområde (SE1–SE4).

## Status

Under utveckling. Se pull requests för implementerade funktioner.

## Kör programmet

```bash
mvn clean compile
java -cp target/classes se.lernia.elpris.Main
```

## Krav

- JDK 25
- Maven 3.9+
